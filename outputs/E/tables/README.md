# Tables

`table_e1_threshold_response.csv` and `.md` contain the full Table E.1,
including the `q = 1` reference row.

`table_e1_market_rmst_template.csv` preserves the `q x rho` schema for
market-specific RMST cells. The blank outcome cells are filled by
`threshold_analysis.py --input`.

`design_parameters.csv` records the simulation design. `sample_accounting.csv`
records the market count, collapse count and pooled collapse rate.
